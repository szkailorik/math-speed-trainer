# v26.3 装备切换、装备属性与怪物资源统一报告

## 范围

- 保留原有题库、答题节奏、关卡数量、掉落和主要战斗机制。
- 统一武器、盾牌、魔法的目录数据，并让商店、角色页、战斗快捷栏和战斗计算读取同一份数据。
- 移除未命中名称规则后按哈希随机分配怪物图的逻辑，增加统一怪物记录和资源审计。

## 装备数据与公式

唯一装备目录位于 `js/adventure-system.js` 的 `CATALOG`。

- 武器：`attack`、`speed`、`action`、`special`、`sprite`
- 盾牌：`defense`、`reduction`、`action`
- 魔法：`magicAttack`、`cooldown`、`effect`
- 统一配置：`EQUIPMENT_CONFIG.weaponSwitchCooldown = 60000`

当前输出伤害公式：

`最终伤害 = max(1, 学习伤害 + (武器基础攻击 - 1) + 已就绪魔法攻击 - 怪物防御)`

其中“学习伤害”继续由原有连击、速度评级和战斗道具形成。最后一击显示的数字会截断为怪物实际剩余生命，保证显示值与实际掉血一致。

当前受伤公式：

`实际受伤 = max(0, 怪物心伤害 + 狂暴加成 - 盾牌减伤)`

## 冷却与存档

- 成功切换武器后保存绝对时间戳 `App.adventure.cooldowns.weaponSwitchUntil`。
- 重新打开快捷栏、退出再进入或刷新页面不会重置倒计时。
- 角色页和商店也会检查同一时间戳，不能作为绕过入口。
- 魔法按物品ID保存 `magicReadyAt`，每种魔法有独立冷却。
- 旧存档缺少字段时由 `ensureState()` 非破坏性补齐；已拥有物品和积分保留。

## 怪物资源

- `js/monster-registry.js` 提供统一字段：`monsterId/id`、`name`、`image`、`animation`、`description`、`type`、`maxHealth`、`attackPower`、`heartDamage`、`defense`、`attackType`、`rewards`、`specialAbility`。
- `js/character-art.js` 的解析顺序改为：明确图片 → 凤凰特殊资源 → 300只扩展怪明确资源 → 名称谱系 → 同类型保底资源。
- 已删除按ID哈希随机选图的路径。
- 新增 `assets/characters/special/phoenix.png`，用于不死鸟、炎炎鸟王、凤凰和凤凰福克斯。
